Formula Validity

Given an expression, decide whether it is a legal propositional formula under the strict fully-parenthesized grammar. Answer yes or no.

formula ::= var | ( ¬ formula ) | ( formula ∨ formula ) | ( formula ∧ formula ) | ( formula → formula ) | ( formula ↔ formula ) var ::= [A-Za-z][A-Za-z0-9_]*
ExpressionLegal?
A yes — single variable
(A∧B) yes — binary, parenthesized
((A∨B)→C) yes — nested, parenthesized
A∧B no — missing outer parentheses
(A∧B)∨C no — outer ∨ not parenthesized
((∨A)∧B) no — ∨ has no left operand
